# 05 视频服务选型与效果评测

核对日期：2026-09-22。以下仅为官方文档能力核对；未实际调用、未确认账户权益、价格、速度或效果。供应商选择尚未锁定。

## 1. 技术路线选择

| 路线 | 适用 | 本版位置 |
|---|---|---|
| 本地网格形变 | 原物体轻呼吸/摆动、即时互动 | 保底主链路 |
| 图生视频 | 静态输入产生较丰富动作 | 照片动画优先试验 |
| 视频到视频编辑 | 保留原摄影运动再改变主体 | 目标范围独立试验，不能以选帧生成冒充 |
| 云实时编辑 | 连续相机视频变换 | 实时阶段专项评测 |
| 对象转 3D 再驱动 | 多视角、反复操控同一对象 | 当前不依赖 Tripo |

## 2. 候选与官方依据

**Runway：优先图生视频试验候选。** 官方入门文档展示图像与提示词创建异步任务；API 索引也列出视频到视频接口。可以据此验证单帧生成路线，但不推断它支持精确的局部蒙版锁定或满足本项目保真要求。[入门文档](https://docs.dev.runwayml.com/guides/using-the-api/) · [API 索引](https://docs.dev.runwayml.com/api/)

**Decart：视频编辑/实时路线候选。** 官方当前区分实时、Queue 批处理和图像处理。仓库只实现了一部分实时接入代码，官方存在 Queue 能力不等于本项目已经具备拍后视频处理。若保留输入摄影运动成为优先项，再专项测试 Queue。[官方概览](https://docs.platform.decart.ai/getting-started/overview)

**Luma：备选图生视频候选。** 已查文档展示图像关键帧和异步视频生成，同时该指南提示迁移到新的 Agents API 文档。因此需要先核对当前账户实际可用接口，再评测，不能直接把旧示例当最终契约。[官方指南](https://docs.lumalabs.ai/docs/python-video-generation) · [参考接口](https://docs.lumalabs.ai/reference/creategeneration)

本项目拍后优先及推荐顺序是工程建议，不是供应商质量排名。先选择一个已有可用账号的候选，以 3 张图做早期试验；不满足保真硬门槛时只切换一个备选，不同时维护三家。

## 3. 评测素材与步骤

准备 12 张获得使用授权的真实照片：楼宇、树冠、路灯各 4 张。每类包括简单背景、复杂背景、弱光、含文字/行人边界情况。6 张调试、6 张留出；留出集不能用于反复改提示词。若只保留楼宇主动作，增加至少 4 张新楼宇留出图。

授权实际调用后执行：

1. 3 张图各 1 次，确认格式、结果下载、单次费用和是否有原物体动作。
2. 基础通过后 6 张调试，最多每张 2 次；失败原因记录，而不是只留成功样片。
3. 固定模型/提示词动作预设/参数，对 6 张留出各 1 次，不挑最好结果计算通过率。
4. 真实输出导入目标手机，检查最终合成、导出与播放。

预算不足时缩小评测数并披露样本量，不能把未跑样本算通过。需要 2 名观察者独立打分；人员不足时标记单人评估。

## 4. 记录表与评分

CSV 建议字段：sampleId,split,objectType,presetVersion,provider,modelVersion,attempt,providerTaskId,submittedAt,readyAt,ingestedAt,inputHash,outputHash,identityScore,motionScore,backgroundScore,naturalnessScore,artifactFlags,costUnits,currency,result。

每项 1–5 分：原物体可辨认 35%、运动有趣且符合描述 25%、背景稳定 25%、动作自然度 15%。出现主体替换、持续人物变形、严重文字损坏，直接失败，不以总分掩盖。样本权重与阈值属于内部建议，最终准入见 [07](07-测试与验收.md)。

“生成完成”与“用户接受”分开记录。延迟至少分上传、排队、生成、结果下载、最终导出；供应商提供的单段耗时不能作为端到端指标。

## 5. 费用与预算

设单次生成成本 Cg、转码 Ce、存储/流量 Cs、合格率 p：每个合格作品的估算成本 ≈ (Cg + Ce + Cs) / p。只有同币种/同单位才能直接相加。成本包含失败/重做，不能只统计被接受结果。

付费前填写：账户/区域、价格来源及日期、模型版本、单次最大消耗、日上限、总上限、并发上限、允许评测数、责任人。没有预算时云功能默认关闭。

MVP 建议运行器并发 1、每用户同时活跃生成 1；日上限取预算可承受值，不在文档预设金额。报价必须有过期时间与价格版本。停止跟踪不等于取消或退款。

## 6. 适配器契约（拟新增）

`capabilities()` 返回输入类型、画幅、时长、是否支持取消/蒙版、配置版本；`submit(snapshot)` 返回 providerId 或明确不确定错误；`poll(providerId)` 返回 running/failed/result；`fetchResult()` 获取可验证文件。只有官方与实测共同支持才把 capability 标可用。

先用模拟适配器验证状态和失败，再进行真实账号联调。模拟结果只用于测试，展示必须标明。云异常不静默回退本地成功。

## 7. 放弃/切换条件

两轮调参后仍主要在新增物体而非原物体运动，或保留集出现系统性身份变化，则关闭该动作预设；若所有动作预设都失败，保留本地版并调整云路线。超出预算不自动改用另一个付费服务。SDK 与模型版本锁定，升级重跑最小留出集。

## 8. 视频输入独立关口

如果启用 video-edit，另备 6 段授权短视频，覆盖固定机位、慢移和遮挡。比较原摄影运动、对象身份、目标运动和帧间闪烁；只在固定机位通过就只开放该范围。用静态帧生成的结果不能计入视频编辑通过率。产品叙事不作为逐视频内容生成任务。
