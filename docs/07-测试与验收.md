# 07 测试与验收

以下为建议目标，不是实测结果。M0 锁定设备/浏览器、网络、输入类型和样本后测量。核心是原物体动画与创作闭环，不验收内容剧情。

## 已有基线

2026-09-21：22 个模块语法、43/43 Node、7/7 CLI/HTTP/SQLite、构建通过。包内旧浏览器记录是历史材料。这是旧版基线。2026-09-22 新版本已加入领域、后端、真实 HTTP 浏览器、视频和模拟相机测试；最新数量与可复验命令见 [09](09-开发进度与证据.md)。真机、真实街景质量和实际云供应商仍待验证。

## 需求映射

| ID | 检查 | 完成条件 |
|---|---|---|
| F01 | 拍照、旋转、视频选帧、损坏/超限 | 输入方向正确；frame/edit模式区分；无静默丢弃视频运动 |
| F02 | 裁剪、留白、横竖屏、重选 | 选区坐标与输入一致，修改使旧预览失效 |
| F03 | 动作更换、版本变化、对象不适用 | 提示明确；旧作品保留快照 |
| F04 | 关闭光效检查原物体 | 真实局部运动，非整图缩放，无严重裂缝 |
| F05 | 参数、对比、可选长按/按钮 | 本地即时可见；云修改不假装实时更新 |
| F06 | 6/10秒导出、后台中断、编码失败 | 可解码，预览一致；中断不报完整成功 |
| F07 | 重开、满额、隐私模式、删除失败 | 持久/临时状态真实，错误不丢数据 |
| F08 | 拒绝相机、10次切换、5次恢复 | 不遗留轨道和对象URL，草稿可恢复 |
| F09 | 超时/刷新/并发额度/重启/下载失败 | 不重复生成与预留；未知保留；实际入库才成功 |
| F10 | 拒绝结果、返回修改、重做 | 新旧结果分离，计费含义明确 |

## 自动测试重点

领域：坐标与裁剪、polygon校验、动作参数限制、固定时间/seed重复绘制、快照版本、幂等指纹包含inputMode及片段。

服务：会话隔离、媒体类型/尺寸、报价过期与幂等恢复、额度竞争、未知提交、stop回包竞态、ingest只重下载、SSRF防护、迁移/重启、媒体缺失。

浏览器：真实HTTP完整创作链路、选帧、参数、预览对比、作品重开、导出中断。布局模拟不代替手机硬件。人工质量检查不能由像素快照替代。

## 设备与性能

iPhone Safari、Android Chrome各至少一台，记录型号、版本、存储、网络；桌面Chrome做回归。手机相机使用可访问HTTPS，电脑HTTP不是等价环境。

- 本地720p连续30秒，预览帧率中位数≥24 FPS，记录低分位；参数/触摸到可见反馈p95≤150ms。
- 每台手机连续10次导出可播放，6/10秒目标容差±0.5秒，无黑屏/比例错误。
- 10次切输入、5次后台恢复、5分钟体验无崩溃，检查发热与内存趋势。
- 云延迟分上传、排队、生成、下载、导出记录；不预先承诺时间。小样本p95须披露样本数。
- WebM无法在目标分享端播放时需转码或明确缩设备范围，不能以下载成功代替可用。

## 视觉门槛

主动作至少10张未调参的真实图片，≥80%通过身份、动作、背景检查；扩展动作每个至少4张，≥3张通过才开放。主体替换、严重人物/文字变形、没有原对象运动直接失败。

若开放video-edit，另外至少6段真实视频，检查摄影运动保留、帧间一致性与遮挡。只固定机位通过就只承诺固定机位，不用图片合格率替代视频指标。

模型评分见 [05](05-模型选型与评测.md)，记录所有尝试而非挑成功案例。系统判断生成完成与用户认可效果分开。

## 用户验证

5–8名陌生用户，≥80%无需口头指导完成一次本地创作，≥50%主动尝试第二对象；记录保存/分享意愿。询问是否认得原物体、是否有趣、是否知道怎样修改，不问能否复述内容剧情。结果仅用于迭代，不推断市场或疗效。

本地版需F01–F08与至少A01通过；云版额外F09/F10、真实服务、预算权限清理恢复通过；F11分能力开放。数据串户、重复计费、伪成功、不可播放、主体不动都是发布阻断。
