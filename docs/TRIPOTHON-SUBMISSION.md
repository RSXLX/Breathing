## Short description

Make the everyday world move. Breathing turns still objects in your photos and fixed-camera videos into playful, animated moments you can save and share.

## A gift for

The part of us that still notices wonder in ordinary places.

## Project description

We walk past the same buildings, trees and street corners every day. Breathing invites us to look again: what if a building could breathe, or a familiar object could gently sway?

Capture or import an image, select the original object, choose a motion, adjust its strength, and preview the transformation. Save an image or a short animated video, and return to your creations in a local library. The object remains recognizable, so the surprise comes from an everyday scene doing something unexpected.

The working browser MVP uses local region-based image deformation. It includes rectangle and polygon selections, motion controls, before/after comparison, framing controls, video export, drafts and a browser-local library. The source project also supports fixed-camera video processing and includes an Ionic/Capacitor mobile shell, iOS/Android projects and server-side adapters for optional generation services.

The public GitHub Pages demo demonstrates the local creative workflow without API keys. Hosted cloud generation is not enabled. Physical-device acceptance and real paid-provider integration remain unverified. This submission does not claim spatial AR or actual use of a sponsor tool for its demonstrated local effects.

## Demo walkthrough

1. Open the browser demo and choose an illustrated sample or import a photo.
2. Select the object with a rectangle or polygon.
3. Choose a motion and adjust intensity and period.
4. Hold the before/after comparison to see the original.
5. Export a 6- or 10-second video, or save a still image.
6. Open the local library to revisit the saved work.

Keep the browser in the foreground while recording. Export format depends on the browser. The included illustrated samples are original demo illustrations, not proof of a real-world camera capture or AI generation.
