## 可复现检查

在源码目录运行：

```sh
npm ci
npm run verify
python3 tests/runtime_smoke.py
# 需安装 Playwright 及 Chromium；也支持 PLAYWRIGHT_MODULE 指定已有模块路径
npm run test:browser
npm run test:video
npm run test:cloud
npm run test:app
```

`test-results/bc3/` 保存报告、浏览器截图和视频样片，不提交用户素材。最近各专项结果：

- 单元/服务测试：62 项通过。
- HTTP 运行检查：7 项通过，付费调用 0。
- 原图创作浏览器：13 项通过，1280×720 的约 6 秒样片可解码。
- 视频/相机浏览器：11 项通过，约 10 秒视频可解码；相机是模拟设备。
- 云生成浏览器：12 项通过，测试使用注入的供应商；断网重试只产生一个任务。
- App 浏览器：10 项通过，导航、选区对齐、导出、作品库刷新恢复与本地资源检查。

GitHub Actions 已配置以上检查，尚未推送/运行远端 CI。当前本机报告不能当作远端 CI 结果。

iOS 模拟器构建、实际编辑、6 秒 MP4 导出回放和系统分享面板已验证；Android Debug APK 已构建、签名校验、安装及启动。Android 原生完整编辑流程、两个平台真机与 iOS 真机签名未验收。包路径和校验和见 [10 App 交付](10-App设计与交付.md)。

## 尚未验收

1. 两个平台真实手机：权限、相册选取、原生拍照、系统分享、长时间运行/发热、存储回收、后台恢复。
2. 至少一批真实街景/日常物体的质量评测；当前插画与合成测试只证明流程。
3. Runway/其他候选真实生成、价格与延迟、失败与未知费用对账。当前付费入口关闭。
4. 原生云服务：真实 HTTPS 部署、跨原生来源的会话设计、服务端监控及数据保留任务。原生包没有嵌入密钥或电脑服务地址。
5. iOS 签名/TestFlight、Android 正式签名/AAB、隐私声明、商店提交与比赛提交。
6. 空间 AR、移动镜头跟踪、自动分割与高质量物体补全是后续能力；Tripo 仍是可选资产路径。
