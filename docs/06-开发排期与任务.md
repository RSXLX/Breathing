## 里程碑与依赖

关键路径：效果/设备 → 输入选区 → 动作预览 → 导出作品。云路径：模型评测 + 会话媒体 → 幂等任务 → 结果入库 → 界面。最终真机回归后交付。

- M0（9/22–23）：原物体确实运动、导出环境明确。失败先修动作。
- M1（9/24–26）：本地创作闭环可独立使用。未通过就暂停扩展。
- M2（9/27–29）：一家云服务真实闭环；视频能力实测后决定开放范围。
- M3（9/30–10/1）：固定版本与参数，用户小测，冻结输入类型和动作数量。
- M4（10/2–3）：回归、修阻断、整理参赛材料。内部目标10/4提交。

日期要求连续可用的人力，普通工作日/休假情况需重排。实时相机效果若是首发硬要求，在 M0 重估，不能仍沿用本表。

## 缩减规则

先减第二/第三动作、系统分享、有声与交互轨迹录制。云质量/预算不过关则关闭云入口，明确 F09/F10 未完成。原视频编辑不过关就关闭 video-edit，保留明确的 video-frame 选帧模式；不能把它算作视频编辑验收。

核心不能删：自己的输入、选中原物体、物体真的动、可靠预览与视频输出、无需开发者代操作。未达到保持未完成。

## 待决策

目标手机与浏览器、首发是否必须连续取景、视频是否必须保留原运动、实际人力、账号预算、部署地址与邀请方式。无预算时云调用关闭；无手机证据时不标真机通过。Tripo 工具赛道不预先选择。

## 工单完成标准

代码、对应需求测试、异常恢复、文档更新齐备。模型接入须额外有真实 task ID、配置快照、输入输出与成本证据；模拟适配器不能当供应商通过。保护工作区已有改动，变更按小工单执行。
