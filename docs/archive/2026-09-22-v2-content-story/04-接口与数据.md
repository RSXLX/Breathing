# 04 接口、数据与任务契约

所有 `/api/v1/*`、数据表和状态均为拟新增，当前源码尚无这些端点。旧 `/api/jobs` 的 Tripo/world 任务保持兼容，避免把两套状态直接混用。

## 1. 身份与通用约定

邀请测试使用服务端随机会话凭据，浏览器 HttpOnly/Secure/SameSite Cookie；兑换邀请凭据需限流。媒体、任务、报价、作品均绑定 `owner_session_id`，每次读写检验所有权。旧共享 ADMIN_TOKEN 只用于管理，不下发成所有用户共用的身份。

请求 JSON，时间 UTC ISO 8601，ID 不承载权限。变更请求检查 Origin 和会话 CSRF token。错误统一 `{error:{code,message,retryable},requestId}`，日志不输出输入图、密钥或服务商完整响应。对象坐标在校正方向与裁剪后的帧上归一化至 [0,1]。

## 2. API 表

| 方法与路径 | 功能 | 主要结果 |
|---|---|---|
| POST `/api/v1/session` | 兑换邀请，建立会话 | 201 + Cookie；错误凭据 401 |
| GET `/api/v1/config` | 当前能力、限制、可用模板版本 | 不含服务密钥；未实测能力不开放 |
| POST `/api/v1/media` | multipart 上传规范化静态帧 | 201 `{media}`，超限 413、错误格式 415 |
| GET `/api/v1/media/:id/content` | 受权访问或 Range 下载 | MIME、长度和缓存策略明确 |
| DELETE `/api/v1/media/:id` | 删除未引用媒体 | 204；活跃任务引用返回 409 |
| POST `/api/v1/quotes` | 校验输入并生成短期额度报价 | 201 `{quoteId,maxCostUnits,currency,expiresAt}` |
| POST `/api/v1/generations` | 带幂等键创建视频任务 | 202 `{job,reused}` |
| GET `/api/v1/generations?cursor=...` | 当前会话任务列表 | `{items,nextCursor}`，稳定游标 |
| GET `/api/v1/generations/:id` | 单任务与可执行操作 | 阶段、耗时、结果、错误、恢复建议 |
| POST `/api/v1/generations/:id/stop` | 停本地跟踪或取消未提交任务 | 200；不承诺服务商取消/退款 |
| POST `/api/v1/generations/:id/resume` | 恢复已有任务查询/入库 | 200；不新建生成 |
| POST `/api/v1/generations/:id/reconcile` | 管理端核对不确定提交 | 仅管理权限；核对后关联 ID 或确认未创建 |
| POST `/api/v1/exports` | 可选转码已上传的本地录制 | 仅设备评测证明必要后实现 |
| GET `/api/v1/exports/:id` | 可选导出结果查询 | 处理阶段与结果 |
| DELETE `/api/v1/session/data` | 删除该会话服务端素材与任务内容 | 202 清理中；终结与审计见下文 |

服务端不接受任意远程媒体 URL。仅允许本会话 mediaId；上传解码验证后重新编码、剥离 EXIF，按实际尺寸和像素数限制，不能只信扩展名。

## 3. 创建任务示例

```json
{
  "mediaId": "media_example",
  "templateId": "building-rest",
  "templateVersion": 1,
  "selection": {
    "kind": "polygon",
    "points": [[0.2,0.15],[0.8,0.15],[0.8,0.9],[0.2,0.9]],
    "objectType": "building"
  },
  "mode": "ai-video",
  "intensity": 0.3,
  "ratio": "9:16",
  "quoteId": "quote_example",
  "confirmed": true
}
```

头：`Idempotency-Key: <client UUID>`。实际返回 `job` 含 `id,state,stage,createdAt,elapsedMs,resultMediaId,actions,error`。未知进度为 null；不能用轮询次数算百分比。provider/model 由配置与报价快照冻结，不允许客户端任意替换。

创建前校验媒体存在/未过期/归属正确，polygon 至少 3 点、非自交、面积有效，坐标和数值范围合法。模板存在、适用对象正确、quote 未过期且指纹一致。

## 4. 幂等、费用与提交

唯一约束 `(owner_session_id, idempotency_key)`。fingerprint 包含 media 内容哈希、裁剪后的选区、模板/版本、动作强度、模型/版本、输出规格和 mode；规范化序列化后哈希。相同键和不同内容返回 409；相同键/内容先返回已有任务，即使原报价已过期也不能重建。

前端在发送前把键、输入指纹与 quoteId 持久化到草稿；超时/刷新后用同一键恢复，不能重新随机生成。重做是用户显式发起的新任务。

SQLite 单事务完成：幂等查找 → 验证 quote → 检查会话/全局额度 → 创建 job → 预留 budget → 提交。无余额 429/额度错误，不调用上游。并发提交要测试竞争。

cost units 用整数计价与币种，禁止浮点金额混算。reserved 表示最坏成本，actual 表示已核实花费，unknown 表示提交不确定。未能核实实际金额时保留预留；确认未发出/未计费才释放。费用上限和价格版本必须先由实际账号验证，不能用此文档的空值开启付费。

## 5. 任务状态机

```text
queued -> submitting -> running -> ingesting -> succeeded
  |            |           |           |
  v            v           v           v
cancelled  needs_review   failed      ingest_failed
                    running -> monitoring_stopped
```

- queued 可取消并释放未使用额度。
- submitting 期间先持久化再调用上游；超时、5xx、不合法响应或服务重启进入 needs_review，不自动再次提交。
- running 仅按 providerId 查询，429/暂时失败指数退避；查询窗口用尽进入 needs_review，不能断言云任务失败。
- ingesting 取回、验证、私有入库，只有文件可解码且完整后 succeeded。
- ingest_failed 重试下载/入库，只复用原 providerId；上游链接过期先查询刷新，不重新生成。
- stop：queued → cancelled；running → monitoring_stopped；submitting/ingesting 返回 409 并说明正在处理。停止跟踪不取消上游和费用。
- resume：monitoring_stopped/needs_review 且已有 providerId → running；ingest_failed → ingesting。无 ID 的 needs_review 仅管理员核对。
- failed/succeeded/cancelled 终态，用户重做建立新 job。原任务保留来源。

后台进程重启需分别处理 submitting、running、ingesting，不把所有任务退回 queued。单运行器原子认领，关机等待有限时长，状态持久化；多实例暂不支持。

## 6. 建议数据实体

| 实体 | 核心字段与约束 |
|---|---|
| `sessions` | id, credential_hash, expires_at, revoked_at；凭据仅存哈希 |
| `media` | id, owner_session_id, sha256, mime, width, height, duration, size, storage_key, state, expires_at, provenance |
| `quotes` | id, owner_session_id, fingerprint, provider/model/version, max_cost_units, currency, price_version, expires_at, consumed_job_id |
| `generation_jobs` | id, owner_session_id, idem, fingerprint, input_media_id, request_snapshot, state, provider_id, result_media_id, next_poll_at, attempts, error_code, created_at, updated_at |
| `budget_entries` | job_id, owner_session_id, scope, reserved_units, actual_units, state；账目改变事务记录 |
| `schema_migrations` | version, applied_at；迁移可重复检查 |
| IndexedDB `drafts` | id, sourceBlob, normalizedFrame, sourceTimeMs, crop, selection, templateSnapshot, pendingSubmission, updatedAt |
| IndexedDB `works` | id, source/provenance, outputBlob或服务器mediaId, templateSnapshot, interactions, exportMappingVersion, caption, saved, createdAt |

媒体文件放 SQLite 之外，库内存元数据与不可公开拼出的 storage_key。临时文件下载完成后校验并原子重命名，再事务挂接媒体记录。断电遗留临时文件定期清理；文件缺失时将媒体标 missing，不能继续报告可下载。

## 7. 生命周期建议默认值

原始云输入 24 小时、云结果 7 天、脱敏任务/额度元数据 30 天；本地作品保留到用户删除/浏览器清理。以上是建议待配置策略，UI 展示实际 expiresAt。活跃引用延后清理到任务明确结束，最长保护窗口 48 小时后由运维核对。

会话到期不能早于其作品保留窗口；凭据丢失的用户无法仅凭 ID 恢复隐私内容。演示使用独立访客会话而非共享库。

删除会话先撤销访问、取消 queued、停跟踪已提交任务，异步删除自有媒体；保留最少成本对账元数据至规定到期。上游已经接收的素材按其保留规则处理，不能声称本地删除即供应商删除。浏览器数据需另行清理并提示。

## 8. 迁移策略

新增表，保持旧 jobs/token_requests 不变；备份旧库后事务迁移。IndexedDB 增加版本、保留原 works 内容，新字段有明确默认来源；迁移失败保留旧数据并允许旧作品下载。UI 以 provenance 分辨旧 demo、本地故事与真实 AI 结果。
