# 07 测试与验收

下列数字为建议验收目标，尚未测得。先在 M0 固定设备、浏览器版本、网络与样本集，再测量。通过节点测试不能代替手机、视觉质量与真实提供商验收。

## 1. 已有基线

2026-09-21 原型验证：22 个 JS 模块语法检查、43/43 Node 测试、7/7 CLI+HTTP+SQLite 检查、构建通过。包内浏览器报告属于更早历史材料。2026-09-22 本次没有改业务代码或重跑真机/云模型，不把旧结果算新需求通过。

## 2. 需求—验收映射

| 编号 | 验收场景 | 完成条件 |
|---|---|---|
| F01 | 拍照、旋转图片、视频 seek、损坏/超限文件 | 正确方向/比例；选中帧可重复；错误可返回；未上传整段视频 |
| F02 | contain 留白、裁剪、横竖屏、重选对象 | 归一化坐标与原帧一致，点选留白无效；选区改变使旧结果失效 |
| F03 | 模板更换、版本升级、不支持对象 | 提示明确；旧作品按旧快照重播 |
| F04 | 关掉字幕/光效观察原物体 | 物体局部真的运动；背景不整体缩放；边界无严重撕裂 |
| F05 | 长按、按钮、取消、自动播放、后台恢复 | 状态正确；交互可见；AI 片段不会声称实时重生成 |
| F06 | 10 秒导出、重播、隐藏页面、编码失败 | 最终文件可解码；字幕/结局一致；中断不显示完成 |
| F07 | 重开、清理、满额、隐私模式、删除失败 | 持久状态真实；临时/删除失败提示明确 |
| F08 | 拒绝相机、10 次输入切换、5 次后台恢复 | 无遗留占用；可恢复当前草稿或明确原因 |
| F09 | 超时、刷新、相同键重发、并发额度、重启、上游失败 | 不重复提交/重复预留；未知状态保留；真实文件入库才成功 |
| F10 | 原片比较、拒绝、下载失败、重做 | 新旧任务和结果分离；不复用错误结果冒充成功 |
| F11 | 扩展模板与系统分享 | 每模板独立质量通过；分享不支持能下载 |
| F12 | 后续能力 | 当前未实现，不计入验收通过率 |

## 3. 自动测试重点

领域：故事状态转移；时间轴映射；固定时间/seed 的重复结果；polygon 校验；坐标变换；幂等指纹字段完整。

服务：未认证/跨会话访问；真实文件类型与像素超限；重复键冲突；报价过期但已有任务返回；额度并发；提交不确定；ingest 失败只重下载；stop 与回包竞态；临时 URL 过期；禁止内部地址下载；迁移与重启恢复。

浏览器：完整本地故事、选帧、修改选区、键盘替代、作品重开、导出中断。真实 HTTP 页面和独立预览分开测，不用直接注入 HTML 的结果冒充服务端 UI 验收。

视觉质量由真实素材比较与人工检查完成，像素快照只能防某些回归，不能证明动作自然。

## 4. 设备矩阵

| 环境 | 需要记录 | 核心项目 |
|---|---|---|
| iPhone Safari | 型号、iOS/浏览器版本、可用存储 | 相机、触摸、后台、输出格式、相册/下载、持久化 |
| Android Chrome | 型号、系统/浏览器版本 | 同上，另记录中档设备发热 |
| 桌面 Chrome | OS、版本、GPU | 开发回归、视频导入、故障注入 |

模拟手机宽度只验布局。相机测试使用 HTTPS 或设备自己的 localhost；手机访问电脑 HTTP 地址不能算正常相机环境。

## 5. 性能与稳定目标

- 本地 720p 预览持续 30 秒：帧率中位数 ≥24 FPS，报告低分位；触摸到本地可见回应 p95≤150 ms。
- 导出：每台设备连续 10 次完整导出 10 秒视频全部可播放，时长容差±0.5 秒，无黑屏/错误比例/缺失字幕。
- 稳定：10 次输入切换、5 次后台恢复、5 分钟持续体验无崩溃；检查相机轨道、对象 URL 与内存持续增长。
- AI 延迟：首次小样记录端到端 p50/p95，不预先承诺生成时间。6 张留出不足以稳定估计 p95，样本数一并展示；生成等待与首次交互时长分开统计。
- 本地导出若只能 WebM且目标手机不可用，必须补转码或缩支持设备并明确说明，不以有文件下载作为通过。

## 6. 视觉与故事门槛

主故事至少 10 张未参与调参的真实输入，≥80% 通过原物体身份/动作/背景三个检查；小样本只是准入参考。扩展故事各有至少 4 张留出且 ≥3 张通过，否则先关闭。

AI 评分见 [05](05-模型选型与评测.md)。出现原对象被替换、严重人物/文字变形或没有实际主体运动则该样本失败。保留所有尝试，报告第一次生成合格率和重做率。

5–8 名陌生用户：≥80% 无口头指导完成本地第一段故事；≥50% 主动尝试第二对象；多数能说出“我做了什么、它怎么回应”。同时记录不懂、等待中退出和不愿保存原因。不能以小样本推出市场规模或健康效果。

## 7. 证据格式

后续在源码 `test-results/bc2/<日期>/` 存报告（默认不提交用户素材），人工选定可公开样例另放授权目录。

```json
{
  "requirement": "F06",
  "device": "待填写真实型号",
  "browser": "待填写真实版本",
  "build": "待填写实际构建标识",
  "mode": "local-story",
  "inputId": "sample-01",
  "status": "not_run",
  "checks": {"decodable": null, "durationSeconds": null, "reopened": null},
  "evidence": [],
  "limitations": []
}
```

状态只使用 not_run/pass/fail/blocked，不把未知写成 0 或通过。视频证据记录输入、交互和导出实际回放；敏感素材需授权和受限存储。

## 8. 发布门禁

本地版：F01–F08 全通过，至少 S01 通过视觉与用户小测。云版额外要求 F09/F10、真实提供商证据、额度/权限/清理和恢复测试通过。模板可单独关闭，不能以整个 App 正常替代该模板通过。

发布阻断：数据串户、重复付费、结果伪成功、导出不可播放、原物体不运动、核心故事操作不完整。非阻断问题列明设备/范围，不以“已知问题”规避核心要求。
