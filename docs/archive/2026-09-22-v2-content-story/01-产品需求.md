# 01 产品需求 PRD

## 产品定义

呼吸城市是有故事的城市魔法相机。用户拍下现实中原本不会动的物体，让同一个物体产生有趣动作，再通过简单操作参与结局。

核心判据：拿掉字幕和外加光效后，仍能看出被选中的原物体运动；用户认得出它就是自己拍下的对象。故事包含对象、处境、用户行动、结局。

面向随手拍摄分享的普通用户与现场体验的评委。第一次使用无需建模、编提示词或准备模型。

## 需求与范围

| 编号 | 优先级 | 需求 | 可见结果 |
|---|---|---|---|
| F01 | P0 | 拍照、图片导入、视频选帧 | 确认将被处理的确切画面 |
| F02 | P0 | 手动框选/多边形选区与类别确认 | 清楚指定哪个原物体运动 |
| F03 | P0 | 故事模板与适用提示 | 选择动作有明确预览和限制 |
| F04 | P0 | 局部原图形变 | 主体发生运动，非整张照片缩放 |
| F05 | P0 | 故事状态与交互 | 操作改变本地强度与叙事进程 |
| F06 | P0 | 导出 10 秒故事 | 字幕、交互结果、片尾一致进入视频 |
| F07 | P0 | 本地作品保存/回看/删除 | 已持久化作品可在重开后找到 |
| F08 | P0 | 权限、损坏输入、后台中断恢复 | 给出下一步，保留可恢复草稿 |
| F09 | P1 | AI 视频提交、状态、恢复、费用确认 | 真正生成后可播放并保存 |
| F10 | P1 | 原片比较、质量反馈 | 可拒绝失真结果；重做明确新任务 |
| F11 | P1 | 另两个故事与系统分享 | 逐模板验收；分享不可用可下载 |
| F12 | P2 | 整段视频编辑、持续取景互动 | 保留输入运动并跟踪目标 |

P0 是最低可用交付，P1 是目标参赛范围。只完成 P0 时标为本地互动特效。P1 云模式开放前需媒体权限、会话隔离与额度控制。

暂不纳入任意对象精准识别、自动长篇编剧、多人空间、3D 市场、硬件、社交账号系统或商业支付。邀请会话身份只服务于数据隔离。Tripo 不在主路径。

## 输入输出约束（建议）

| 项目 | MVP 值 | 说明 |
|---|---|---|
| 图片 | JPEG/PNG/WebP，≤15 MB，≤20 MP | 校正方向、移除 EXIF；不支持格式提示转换 |
| 视频 | ≤30 秒、≤50 MB、实际可解码 | 浏览器本地选择一帧，原运动/音轨不进入结果 |
| 画幅 | 9:16 / 16:9 | 用户确认裁剪；选区随坐标变换 |
| 输出 | 目标 720p，完整故事 10 秒 | AI 动作段约 5 秒，依实际模型能力确认 |
| 音频 | 首版静音可完整理解 | 不请求麦克风；有声后置 |

对外开放时服务端配置返回统一限制。当前原型的导入限制仍是旧值，文档不自动改变代码。

## 成功与失败

成功是用户辨认原对象、理解操作、看到回应、愿意拍第二个地点。失败包括：只加粒子、换成另一个楼、长按没有影响、生成失败以旧片冒充本次结果。

量化目标在 [07](07-测试与验收.md)。分析事件仅含步骤、匿名会话、耗时和失败类型，不把原图、提示词或地理位置写进统计日志。

## 版本路线

V0 本地拍后互动 → V1 AI 动作生成 → V1.5 整段视频处理 → V2 实时跟踪与变形 → V3 有需求时的原生 App 和空间 AR。

手机 Web 是验证形态，不承诺原生权限、后台任务或空间锚定。实时本地形变和云实时生成分别验证，不能共用性能承诺。
