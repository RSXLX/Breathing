# 00 产品叙事：让熟悉的世界重新变得有趣

2026-09-22。用户确认的核心：通过镜头和视频，让画面里原本静止的东西有趣地动起来；“故事”指产品为何存在及其价值，而不是要求每段作品都有剧情。

## 为什么做

我们每天经过同样的楼、路灯和街角，熟悉让它们逐渐退到注意力之外。呼吸城市想提供一次很小的视角变化：如果眼前的楼能够呼吸、路灯轻轻摇摆、雕像伸个懒腰，我们会不会重新看一眼这些普通的地方？

这是产品的创作动机与待验证假设，不是已经证明的用户需求或心理健康结论。

## 为谁做

先面向愿意随手拍摄、尝试新鲜视觉并分享给朋友的普通用户。次级用户是内容创作者与活动体验者。先验证个人惊喜与分享意愿，不急于增加专业视频编辑或社交平台能力。

## 我们给用户什么

一个直观的动作：拍下它，选中它，让它动起来。

惊喜来自“还是那个东西，却发生了不可能的小变化”。对象身份和现实背景越能保留，魔法感越成立。外加角色、换掉整栋楼或全画面风格化，可以是其他玩法，但不能代替首版的核心效果。

## 为什么是相机式 App

镜头连接用户眼前的现实，选对象和调动作让用户掌握创作，预览与导出让惊喜可以保存。App 是完整体验的载体，可以先以手机网页实现；是否需要原生和真正空间 AR，取决于后续技术与使用验证。

## 对外介绍建议

一句话：**呼吸城市，让你镜头里的静物有趣地动起来。**

简短介绍：我们习惯记录世界原本的样子。呼吸城市让你尝试另一种观看方式：拍下身边的建筑、路灯或雕像，给它一个动作，看熟悉的地方变得不一样，再把这份惊喜分享出去。

参赛主题表达建议：**送给日常的一点想象力。** “礼物”是重新看待熟悉世界的体验，无需在每段视频强加赠言或情节。

## 这段叙事如何影响开发

| 产品主张 | 开发取舍 | 验证问题 |
|---|---|---|
| 来自我的现实 | 支持自己的照片/视频，保留原对象 | 用户是否认得出是自己拍的东西？ |
| 简单就能玩 | 动作预设、直接预览、少量参数 | 第一次是否无需讲解就能完成？ |
| 有趣且可控 | 原物体运动，强度可调 | 用户是否觉得惊喜，且知道自己改变了什么？ |
| 能分享给别人 | 可靠导出与回看 | 用户是否主动保存或分享？ |
| 重新注意日常 | 鼓励尝试第二个地点/对象 | 用户是否愿意再次拍摄？ |

## 边界

产品故事用于定位、首页与参赛表达。内容默认由用户拍摄的对象和选择的动作决定，不要求角色动机、长按解锁剧情、开场字幕或结局。Tripo 和视频模型是实现手段，只有实质服务核心体验时才加入。
