# 01 产品需求 PRD

## 产品定义

有趣的现实物体动画相机。用户拍摄或导入素材，选择原有静物，为它赋予动作，调整效果后保存。产品叙事见 [00](00-产品叙事.md)，内容无需剧情。

核心验收：关掉字幕、粒子和外加光效，仍能看到原物体运动；用户可以辨认原对象；输入、预览和输出之间关系清晰。

## 功能范围

| ID | 优先级 | 需求 | 可见结果 |
|---|---|---|---|
| F01 | P0 | 拍照、图片导入；视频输入能力显式标记 | 看到实际处理的原帧或视频 |
| F02 | P0 | 手动框/多边形选区与类别确认 | 明确哪个原物体要动 |
| F03 | P0 | 动作预设与适用提示 | 呼吸/摇摆等动作直接选择，没有剧情步骤 |
| F04 | P0 | 原图局部形变 | 原物体真的动，非整张照片缩放 |
| F05 | P0 | 动作预览、参数调节与原片对比 | 强度、速度可调；本地模式即时反馈 |
| F06 | P0 | 导出动作视频 | 输出与预览一致，可播放 |
| F07 | P0 | 本地作品保存、回看、删除 | 重开可找回已持久化作品 |
| F08 | P0 | 权限、输入错误、后台恢复 | 不丢可恢复草稿，不占用遗留相机 |
| F09 | P1 | AI 生成与任务恢复、费用确认 | 一家视频服务真实闭环 |
| F10 | P1 | 质量检查、拒绝、修改后重做 | 改参数可能需新生成，费用明确 |
| F11 | P1 | 更多动作、视频处理与系统分享 | 每个能力单独验收后开放 |
| F12 | P2 | 连续相机目标跟踪与实时变形 | 慢移仍保持对象位置，另行开发 |

P0 为保底范围，P1 是目标范围。若只支持照片，提交说明写照片；如果视频只选帧，明确标记选帧生成。F11 的原视频编辑未过验收时不能宣称已完成。

暂不纳入强制剧情、内容故事编辑器、人物对话、通用编剧、3D 资产市场、硬件和社交账号体系。邀请会话只负责数据隔离。

## 输入输出建议

| 项目 | 建议限制 | 说明 |
|---|---|---|
| 图片 | JPEG/PNG/WebP ≤15 MB、≤20 MP | 方向校正、EXIF 清除，真实格式检查 |
| 视频 | ≤30 秒、≤50 MB | 先确认浏览器解码；处理段建议≤10 秒 |
| 视频选帧 | 可作为明确选择的独立模式 | 原运动与音轨不进入生成结果 |
| 画幅 | 9:16 / 16:9 | 用户确认裁剪，选区随坐标变换 |
| 本地输出 | 720p，6 或 10 秒 | 默认 6 秒；无强制开场、字幕或片尾 |
| AI 输出 | 时长/画幅由实测能力决定 | 生成前展示，不强行剪成剧情结构 |
| 音频 | 首版静音 | 不请求麦克风；视频原音轨不保留时提前说明 |

本地输入已执行上述大小/时长/像素限制，云上传会真实解码并去除 EXIF。云适配器当前仅接受静态照片/视频帧，报价固定 5 秒。真实设备与模型结果仍待验收，见 [进度记录](09-开发进度与证据.md)。

## 用户价值与版本

主指标是首次成功创作与主动第二次尝试。分享/保存为辅助；不能把完成一次特效视为健康疗愈。统计只记录匿名步骤、耗时和失败，不将素材写入分析日志。

路线建议：照片原物体动画 → 受控视频处理 → 实时目标跟踪/变形 → 根据需求决定原生和空间 AR。拍后优先是建议，首发实时需求若确定，应重新排期。
