# 08 运行、发布与参赛

## 1. 当前可执行命令

开发目录：`Breathe-City-All-In-One/01-project/breathe-city/`。从项目根目录执行：

```bash
cd Breathe-City-All-In-One/01-project/breathe-city
npm ci
npm run verify
python3 tests/runtime_smoke.py
npm start
```

默认本机 http://localhost:3000 ，Node.js 22.16+。`verify` 包含语法、Node 测试、构建；runtime smoke 使用临时目录和本地模拟任务，不调用付费服务。源码与构建产物是不同入口，改源码后再构建分发版。

根目录 `.github/workflows/breathe-city.yml` 已配置 Node、运行集成和三组 Chromium 检查；源码内也保留原 CI。Docker 已改为 npm ci 安装运行依赖，但镜像构建、远端 CI 执行和公开部署尚未验证。

## 2. 已实现的运行配置

完整值见源码 `.env.example`。`VIDEO_GENERATION_ENABLED=false` 为默认；本地创作无需 API。

| 配置 | 用途 |
|---|---|
| `VIDEO_GENERATION_ENABLED` | 显式开启云生成 |
| `RUNWAY_API_KEY` / `VIDEO_MODEL` | 服务端密钥与 gen4.5 或 gen4_turbo |
| `DATA_DIR` | breathe.sqlite、generation.sqlite、private-media 所在私有目录 |
| `PUBLIC_ORIGIN` | 页面实际来源，HTTPS 时签发 Secure Cookie |
| `INVITE_SECRET_HASH` | 邀请凭据的 SHA-256，小写 64 位 hex |
| `VIDEO_MAX_COST_UNITS` | 单次最坏预留额度 |
| `VIDEO_SESSION_BUDGET_UNITS` / `VIDEO_DAILY_BUDGET_UNITS` / `VIDEO_TOTAL_BUDGET_UNITS` | 会话、UTC 日和累计额度上限 |
| `VIDEO_COST_UNIT` / `VIDEO_PRICE_VERSION` | 整数计量单位与核实后的价格版本 |
| `VIDEO_RESULT_HOSTS` | 逗号分隔的精确 HTTPS 结果域名，非任意 URL |
| `VIDEO_POLL_MS` | 正常查询间隔，默认 5000 ms；失败延后 60 秒 |
| `ADMIN_TOKEN` | 对账管理端认证，不能作为共享访客身份 |

启用云模式时任何必要密钥/预算/价格版本/域名缺失会阻止启动。密钥只在服务端；价格、域名和供应商实测未完成前保持关闭。当前是单机单进程，数据目录写入锁防止重复启动；不支持共享网络卷多实例。

## 3. 发布前准备

1. 记录版本与源码状态，确认新功能验收；保留原始 ZIP 和基线。
2. 受控 HTTPS 地址、正确 Origin、私有媒体卷、邀请会话、提供商预算和关闭开关到位。
3. 已提供 `/api/v1/ready`，检查：数据库可写、私有盘可用、必要迁移完成；liveness 单独判断进程。原有 health 的 200 不证明这些条件。
4. 备份 SQLite 与媒体清单，实际试一次恢复；WAL 模式使用数据库备份机制或停止写入后完整备份，不能只复制正在写的主库文件。
5. 发布候选版本，执行一次真实手机闭环；云入口先只对测试会话开放，验收后才扩大。
6. 保存发布标识、配置版本（去密钥）、设备证据、回退版本和责任人。

当前实现与验证均在本地，没有公开部署、发送邀请或提交比赛。

## 4. 运行观测与成本

记录请求 ID、内部 jobId、脱敏 providerId、动作预设/模型版本、状态转换、各阶段耗时、已知/预留成本、文件大小与错误码。主看成功生成率、用户接受率、导出成功率、重复提交数、未知成本和磁盘占用。

供应商计费与本地账目定期核对，异常时关闭新生成，保留已有任务查询。磁盘阈值触发停止新上传，不能覆盖旧作品以维持“正常”。

结果失效显示明确状态。为演示准备授权的历史样例，标明预先生成与制作时间；断网时可以体验本地原物体动画，不能把旧样例冒充刚刚生成。

## 5. 回退与清理

回退顺序：关闭新生成 → 等待/记录当前任务 → 备份 → 切换兼容旧数据库的新旧构建 → 健康与作品读取验证。保留新表的加法迁移优先，避免为回退直接删库。新增媒体不随构建删除。

清理遵循 04 的到期与引用规则。删除只针对当前会话自有内容，带 pending 状态直到存储实际完成；动作预设升级不改已有作品。设备浏览器数据清理会删除本地作品，UI 在保存时说明。

## 9. 离线备份与恢复演练

从源码目录执行。先正常停止服务，备份目的目录必须在数据目录外且不存在；恢复只能写入新目录，不覆盖当前数据。程序会拒绝持有写入锁的服务实例。旧版不支持该锁的进程也必须手动正常停止。

```bash
node tools/data-backup.mjs backup ./data /absolute/path/breathe-backup-20260922
node tools/data-backup.mjs restore /absolute/path/breathe-backup-20260922 /absolute/path/breathe-restored-20260922
```

备份含 SQLite/WAL、私有媒体和 SHA-256 清单，目录/文件权限限制为 700/600；不包含服务端 .env，也不包含访客浏览器 IndexedDB。备份含隐私数据，使用私有存储。恢复校验文件清单/哈希与 SQLite quick_check；恢复后使用新 DATA_DIR 启动并检查 ready、作品访问和任务状态，再决定切换。

已用临时数据验证数据库记录、媒体、哈希破坏拒绝、拒绝覆盖和写入锁。尚未以实际生产卷演练。崩溃后仅在原 PID 已不存在时自动清除旧锁；跨主机锁与分布式部署不支持。
