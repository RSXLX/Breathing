# 安全与隐私边界

该底座面向本地、单用户开发与受控演示，不是公开 SaaS。

已做：默认只监听 loopback；真实付费默认禁用；非本地绑定强制管理令牌；Origin + 自定义请求头保护写入；静态目录边界与符号链接检查；JSON 大小限制；操作限流；日任务与令牌额度；不自动重提不确定生成；服务端长效 Key；短期实时令牌；手动 / 超时 / 切出断开；不采麦克风或定位；对象 URL 与轨道清理；导入文件大小检查；外部结果拒绝非 HTTPS 和带用户名密码的 URL。

尚未做：用户账号、租户隔离、每用户资产授权、文件病毒扫描、账单硬限额、生产级审计、服务器数据加密、跨设备同步、长期指标告警、队列多实例锁、自动备份与保留策略、全浏览器 / iOS 验收、外部模型商业授权评审。

重要操作：

- `.env`、数据目录、服务商 Key 不进 Git。前端输入的是管理令牌，不是厂商密钥。
- 源码和截图不含真实凭据。服务状态“已配置”只表示配置存在，不证明账户权限和余额有效。
- Docker 镜像不能打包 `.env`；不要把生成的独立 HTML 当作后端安全控制。
- 开启 Decart 会向第三方发送画面；使用者必须拥有该画面的使用权限。无声不代表没有隐私。
- 作品库和任务库都不是加密保险箱；清理网站数据会丢作品。提示词保存在 SQLite，必要时关服务后备份 / 删除整个 data 目录。
- 部署 HTTPS、反向代理、鉴权后再暴露外网。NAT / 公网绑定与摄像头安全上下文是不同问题。
- 默认实时 30 秒只是本地和服务商请求约束，不能承诺账单金额。先设置服务商控制台预算与告警。
- GLB 是不可信输入。当前解析器有格式 / 大小约束，但不是通用安全审计器；公开服务应使用成熟、维护中的 3D 引擎并增加隔离、资源预算和第三方依赖审计。
