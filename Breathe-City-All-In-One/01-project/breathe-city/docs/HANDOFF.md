# 给下一位开发者 / Codex 的交接

## 产品方向不变

城市呼吸相机：树、建筑、天空决定视觉载体；用户用长按赋予节奏；一次相遇形成可导出短片。不要把它扩成需要账户、社区、交易市场的重平台，也不要把未验证的模型调用伪装成已经可用。

## 当前可用入口

先运行 `npm run verify` 和 `npm start`。阅读 README → ARCHITECTURE → ACCEPTANCE。前端入口 public/js/app.js，视觉在 engine.js，模型接口在 server/providers.mjs。

本地业务无 npm 依赖。启动不需要 build；dist 是可分发预览，需要修改源码后运行 npm run build 更新。不能只改独立 HTML 然后丢掉源码同步。

## 下一个迭代按顺序做

### BC-001 真实素材集

收集获得授权的城市照片 / 视频，覆盖三类主场景与未知场景，白天、蓝调时刻、夜景、转场。记录预期区域而不是先写“准确率高”。先跑现有导入功能、确认比例和录制无问题，再评估模型。

### BC-002 语义模型联调

验证 Transformers.js 固定版本、实际模型权重和 RawImage 输出；跑目标桌面与手机的模型下载、单帧推理、标签映射和错误降级。把下载依赖改为可复现、自托管路径；保留颜色规则作为明确降级，不删除来源标记。

### BC-003 一件真实 Tripo 资产

用 1 次真实调用验证当前账号 API 权限、输出结构、压缩格式、CORS 与 GLB 查看器。GLB 不兼容时优先换成熟 glTF 渲染库并固定依赖，不伪造资产链接。验收成功之后才标记“真实接入已验证”。

### BC-004 一次真实 Decart 会话

固定已验收 SDK 版本。检查 token 限制、首帧、场景变更、停止发送、SDK 内部重连事件与计费。应用已经订阅事件并在重连时关闭，但不能假设 SDK 或提供商全部按预期执行；必须用真实账号证据确认。

### BC-005 浏览器和设备测试

相机权限拒绝 / 设备缺失、导入损坏、后台恢复、10 次源切换、录制中关闭、存储配额不足、重开页面持久化。特别检查 iOS Safari 的 MediaRecorder / captureStream 支持情况与 fallback。导出的 WebM 是否需要服务器转 MP4，应根据目标平台确定，不先宣称全平台兼容。

### BC-006 叙事与资产质量

当前插画与程序化 GLB 是演示用原创样例。实际比赛主片应使用授权街景、统一设计的 Tripo 生命体，以及持续录屏证明交互。World Labs 可做片尾文字世界扩展，不挡住相机主链路。

## 不要顺手做的事情

不修改线上数据库；不填写 / 发送真实 API Key；不开启付费开关；不公开部署；不默认上传摄像头画面；不新增四个 Worker；不把 2D 区域资产叫空间锚点；不宣称模型准确率、真实延迟或疗愈效果未经测量已经成立。

如需重构为 TypeScript / React，先保持现有33项交互验收和43项Node测试的语义，再迁移，不要先重写视觉与业务规则。
