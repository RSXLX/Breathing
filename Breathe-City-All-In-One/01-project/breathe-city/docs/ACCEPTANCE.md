## 必须在用户设备执行

### P0：本地产品闭环

打开 http://localhost:3000，允许相机，前后摄像头至少一个目标设备验证。导入一段真实街景，确认像素比例、横竖切换、慢移镜头、快速切场、导入失败与取消权限均可恢复。录制 6 秒后播放、下载、关闭页面再重开作品库，确认作品与名称保留。清理网站数据再确认作品删除符合提示。

### P0：真实语义模型

在正常服务模式主动开启，确认依赖和权重下载成功、能输出实际分割而非颜色规则；检查标签对应。记录模型推理耗时及首次加载时间。测试暗光、招牌、行人、复杂树冠和未知场景。识别失败必须标记并退回安全的规则 / 原片，不编造置信度。

### P0：付费服务逐家联调

Tripo：一次提交 → 一个 provider ID → 下载有效 GLB → 实际预览 → 应用。World Labs：一次文字提交 → operation ID → 实际世界地址。Decart：临时令牌 → 首个远端帧 → 场景提示改变 → 本地倒计时与服务端时限 → 断线 / 切后台释放 → 服务商控制台费用核对。打开真实开关前先设置厂商预算。

### P1：真实使用质量

用未参与调试的街景测试泛化；记录效果漂移、画面保护区误判、输入到显示的延迟、首次生成耗时和任务失败率。不要用这次演示设备的 FPS 当手机端承诺。

### P1：公开部署前

HTTPS、准确 Origin、用户认证与资产权限、依赖版本锁定 / 自托管、成本控制、日志去敏、服务监控、数据库备份与任务租约。Dockerfile / GitHub Actions 已提供，但本次没有构建镜像、触发远端 CI 或做生产部署。

## 演示时怎样准确介绍

“当前是城市区域感知 VFX 底座。无密钥时跑本地特效；真实生成服务是可配置扩展。录制、作品库、模型导入和任务管理已经成链。真实街景泛化与厂商付费能力需要在目标设备继续验收。”
