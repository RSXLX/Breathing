# 启动、手机访问与部署说明

本说明按当前包内代码编写，不是已公开上线的服务部署记录。

## 桌面本地

```bash
cd 01-project/breathe-city
node --version
npm start
```

Node 版本要求见 `package.json`（>=22.16.0），入口是 `http://localhost:3000`。不必先构建或安装 npm 依赖。也可运行总包的启动脚本；脚本不会自动安装 Node。

修改源码后执行 `npm run build` 更新独立 HTML 和静态前端。`02-demo/Breathe-City-Preview.html` 是此次归档副本，不会随着开发自动同步；重新发布时应使用新构建结果。

## 手机

先在电脑验证导入素材；再处理手机访问、受信任 HTTPS、相机授权、后置镜头、录制与存储。电脑上的 localhost 指电脑本机，手机上的 localhost 指手机本身，不能直接照抄地址。

当前默认 `HOST=127.0.0.1`；变更非回环监听时必须设置至少 24 字符的管理令牌。手机访问电脑普通局域网 HTTP 地址并不保证能使用摄像头。使用受信任 HTTPS 与准确 `PUBLIC_ORIGIN`，禁止靠关闭系统安全机制解决权限问题。

不要只改 `HOST=0.0.0.0` 就公开上网。当前是单用户开发工具，没有完整多租户认证、计费、云对象存储或生产访问治理。外网发布前按原项目 `docs/SECURITY.md` 与 `docs/ACCEPTANCE.md` 验收。

## 数据位置

浏览器：作品媒体保存到 IndexedDB，失败时明确降级为临时会话内存；不存在自动跨设备同步。

后端：任务与提示词在本地 SQLite。使用 Docker 时需要数据持久卷。清理浏览器数据与删除后端数据库的影响不同，先导出重要作品，再清理。

本包不包含用户摄像头素材、真实密钥、运行中的 SQLite 数据库或生产配置。

## 典型排查

| 症状 | 优先检查 |
|---|---|
| `node` 找不到 | 先准备满足版本要求的运行时，再启动 |
| 服务启动失败 | 终端错误、Node 版本、端口冲突、环境配置 |
| 手机相机打不开 | 安全上下文、权限、真实访问地址和浏览器兼容性 |
| 规则识别不准 | 这是当前规则模式边界，导入更多素材测试，不假称 AI 模型已启用 |
| 真模型下载失败 | 网络、模型/依赖版本、设备支持；保留原画面或规则降级 |
| 作品刷新后丢失 | 确認是否已进入临时存储模式；先下载作品，后续真机验收 IndexedDB |
| GLB 加载失败 | 24 MB 限制、静态未压缩格式、压缩/蒙皮与贴图支持 |
| 点真实接口无结果 | 管理令牌、付费开关、对应密钥、任务 ID、实际账号权限与接口结构 |

更详细的命令与配置以 `01-project/breathe-city/README.md` 为准。Dockerfile 随原项目保留，本次没有构建或启动 Docker 镜像。
