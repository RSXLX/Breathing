# 实体呼吸灯：装配与联调开发说明

**状态：后续实现方案，不是随包已经完成的功能。没有已编译固件、PCB、完整接线图或已验收打印件。**

## 目标体验

按住按钮：本地灯光与屏幕内的城市生命体一起增强。
松开按钮：它们平滑回到待机亮度。
连接中断、页面关闭或控制数据超时：灯光回到安全待机状态，而不是无限保持最高亮度。

现有网页交互已经支持长按与空格键。最小按钮演示可以研究 HID 键盘映射；这只解决按钮输入，不自动实现灯光同步。具备原生 USB HID 的实际板卡必须另行确认。

## 实现边界

### 路线 1：先做独立实体灯

按钮连接控制板，控制板独立驱动灯光。电脑仍用网页长按进行演示。这可以先验证灯罩均光与手感，但必须说明“尚未同步”，不能把两边手工同时触发称为软件联动。

### 路线 2：接入项目状态

新增前端 HardwareBridge、后端设备通道和控制板固件。只同步归一化的艺术交互状态，不传摄像头原始画面、不声称获得心率。

推荐定义的数据字段（接口设计草案，目前没有对应路由）：

```json
{
  "protocolVersion": 1,
  "sessionId": "local-demo-session",
  "sequence": 42,
  "pressed": true,
  "intensity": 0.6,
  "cycleSeconds": 5,
  "enabled": true,
  "ttlMs": 2000
}
```

设备应校验类型和范围、丢弃过期/乱序状态、对变化平滑处理；强度上限由实物热测试和供电能力确定。`ttlMs` 是本设计提议的有效时间字段，不是目前系统里已运行的机制。

控制方式先选一种：USB 本地串口桥接，或局域网设备桥接。不要默认所有移动端浏览器都支持同样的直接硬件接口。

## 机械装配流程

先测量开发板、灯环、电源接口和按钮 → 画安装/走线草图 → 用纸板或低成本样件校核尺寸 → 打印小样验证透光和装配 → 完整打印 → 断电接线与绝缘检查 → 限亮度通电测试 → 外壳温升和稳定性测试。

CAD 图需标明板卡安装孔、灯环固定位置、按钮开孔、线缆通道、底部检修口、散热空间、重心与防滑结构。不得依据这里的文字直接把未校核模型送去量产。

## 电气与现场检查

由具备经验的人员核对实际器件数据表、供电、驱动、电平和负载。使用合适的低压电源；接口绝缘，线缆可靠固定，避免可接触短路点。不要从未知规格 USB 口或控制器 GPIO 直接带大负载。

测试范围：首次通电、按住/松开、持续亮灯、控制断线、电脑休眠、浏览器退出、设备重启、连按、底座倾倒风险。公共展示前还需确认场地许可、通行空间和线缆管理。
